Installation
============

The installation process is straightforward and can be completed in a few simple steps.

Prerequisites
-------------

- FLORunner v1.0.0.7z
- An existing FLO-2D installation with the FLOPRO executable available

Installation Steps
------------------

.. Note:: FLORunner is installed with FLO-2D Setup Package.  To update a stand alone version follow these steps:


#. **Download the software**

   Download the FLORunner archive from the FLO-2D ShareFile repository.

   .. figure:: img/florun001.png
      :align: center
      

#. **Extract the files**

   Unzip the downloaded archive to a preferred location on your computer.

#. **Copy files to the FLOPRO directory**

   Copy all extracted files into the FLOPRO installation directory,
   where FLO-2D is installed.

   * FLO-2D is typically installed in
     ``C:\Program Files (x86)\FLO-2D Pro``.
   * Ensure that ``FLORunner.exe`` is located in the same folder
     as the FLO-2D executable.
   * Verify that the ``resources`` and ``ui`` folders are also
     present in this directory.

   .. figure:: img/florun002.png
      :align: center
      

#. **Run the application**

   Double-click ``FLORunner.exe`` to launch the application.

   * FLORunner can also be launched from the FLO-2D Plugin in QGIS.

#. **Verify the installation**

   When the application opens, confirm that the **Run** button is
   enabled. This indicates that FLORunner successfully detected
   the FLOPRO installation.

   .. figure:: img/flo_runner_install.png
      :align: center
