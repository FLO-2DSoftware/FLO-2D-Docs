Run FLO-2D Map Crafter
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
- Run MapCrafter and load the project run folder.
- Review the Summary.
- Select the maps to create.
- Move the MapCrafter Group to the best location on the Layers list.

Set up Results Folder
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
- Load the Results folder.
- Check the folder path is valid.
- What's in the folder?
- HYCROSS.OUT, HYCHAN.OUT, HYSTRUCT.OUT
- Channel profiles and results
- Time dependent data
- Storm drain profile and results
